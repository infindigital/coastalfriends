# Coastal Friends

## Static website: `static-site/`

`static-site/` is a complete, standalone HTML copy of https://coastalfriends.org. It doesn't need WordPress, a database or the old site.

* **81 pages**: every page, every news post, category/tag/author archives and all their pagination (`/page/2/` … `/page/13/`, `/gallery/2/`, `/gallery/3/` …), plus `404.html`.
* Each page is `<path>/index.html`, so the URLs stay exactly the same (`/about-us/`, `/ifthar-party-2/`, `/category/gallery/page/2/` …).
* All CSS, JavaScript, fonts and images are inside the folder at their original locations (`wp-content/…`, `wp-includes/…`). Every link is relative, and nothing is loaded from the old site.
* The contact forms work: `wp-admin/admin-ajax.php` is a small PHP script that emails each submission to `info@coastalfriends.org` (change `$cf_to` at the top of that file). It needs PHP `mail()`, which Hostinger provides.
* `.htaccess` sets `index.html` as the folder index and serves `404.html` for missing pages.

### Upload to Hostinger
1. Hostinger hPanel → **File Manager** → open `public_html` and delete the old WordPress files (keep a backup).
2. Upload `coastal-friends-static-1-site.zip`, `coastal-friends-static-2-images.zip` and `coastal-friends-static-3-images.zip` into `public_html` and **Extract** each one there. They fill the same folders.
3. Open https://coastalfriends.org/ to check it. Send a test message from the Contact Us page.

### Rebuild
```bash
python3 -I tools/build_static.py site coastal-friends/assets static-site
```

## Page copies: `site/`

`site/` holds the exact rendered HTML of **every public URL** on https://coastalfriends.org (81 URLs: pages, all news posts, category/tag/author archives and all their pagination) plus the 404 page (`site/404.html`), downloaded as served. `site/<path>/index.html` is the copy of `https://coastalfriends.org/<path>/`.

## WordPress theme: `coastal-friends/`

A classic WordPress theme that reproduces the whole site and **runs on real WordPress posts**. It works on an empty WordPress install: no pages, Elementor or PRO Elements are needed.

**Posts are live**
* On first activation the theme imports the **36 original posts** as normal WordPress posts: original content (galleries, lightbox, YouTube embeds), date, excerpt, featured image (added to the Media Library), categories (Gallery, Event) and all 17 tags. Posts whose slug already exists are skipped, so nothing is ever duplicated or overwritten. **Tools → Coastal Friends Import** adds back any original post that is missing.
* Every post grid reads real posts, printed with each grid's original card markup (`inc/post-widgets.json`):

  | Grid | Shows |
  |---|---|
  | Home "latest posts" (Load more) | all posts, 3 per page (`/page/2/` …) |
  | Gallery (Load more) | category **Gallery**, 21 per page (`/gallery/2/` …) |
  | Event | category **Event**, 6 per page |
  | home-1 / SufyHome | 2 newest posts |
  | Category / tag / author pages | that archive's posts, 10 per page with page numbers |
  | "Recent posts" sidebar on archives | the 3 oldest posts (as on the original) |

* A new post appears in every grid its category or tag puts it in. Single posts (old and new) use the original Elementor post design (`single.php`), and archives use the original archive design (`archive.php`). Both are generated by `tools/build_dynamic.py`.

**Pages**
* Home, About Us, Contact Us, Event, Gallery, Our Team, home-1 and SufyHome are served from `snapshots/*.php` (exact original markup) for their URL, even if no such page exists in WordPress. Their post grids are live. Any other missing URL shows the original "page not found" design with a 404 status.
* Until the posts are imported, the old post/archive URLs fall back to copies, so nothing is ever blank.

**Other**
* `assets/` holds the CSS, JS, fonts and images.
* Contact forms: without PRO Elements, `inc/forms.php` emails messages with `wp_mail()` to the address in **Appearance → Customize → Contact form** (default `info@coastalfriends.org`).

### Google Analytics
Appearance → Customize → **Google Analytics**: paste the GA4 Measurement ID (`G-XXXXXXXXXX`) and publish. The theme then adds the gtag.js snippet to every page. By default it doesn't count logged-in administrators (there's a checkbox to change that). Leave the field empty to turn tracking off.

### Install (one file)
`coastal-friends-theme-complete.zip` (≈58 MB) is the whole site, with the posts imported on activation,: the theme plus all 2,582 photos as AVIF (`tools/pack_theme.py … avif 38 70`). The image sizes the pages use are kept, so the layout is unchanged.

1. WordPress → Appearance → Themes → Add New → **Upload Theme** → `coastal-friends-theme-complete.zip` → Install Now → **Activate**. Upload the zip as it is; don't unzip it.
2. Settings → Permalinks → choose **Post name** → Save.
3. Optional: Appearance → Customize → **Contact form** (recipient email) and **Google Analytics**.

If the host's upload limit is under 58 MB, the split build is the fallback: `tools/split_photos.py` makes a small theme zip plus photo zips, installed from Appearance → Coastal Friends Photos.

### Rebuild
```bash
python3 -I tools/crawl.py tools/seed-urls.txt site                     # re-download every public page into site/
python3 -I tools/mirror.py tools/urls.txt coastal-friends/assets       # download assets listed in tools/urls.txt
python3 -I tools/relativize_css.py coastal-friends/assets              # point CSS at local copies
python3 -I tools/build_theme.py site coastal-friends                   # regenerate snapshots + manifest from site/
python3 -I tools/build_dynamic.py site coastal-friends tools/data      # live grids, single.php, archive.php, import data
python3 -I tools/pack_theme.py coastal-friends dist avif 38 70        # AVIF photos, sizes the pages use
(cd dist && zip -qr -9 ../coastal-friends-theme-complete.zip coastal-friends)   # the one-file theme
python3 -I tools/split_photos.py dist/coastal-friends release 15       # release/coastal-friends.zip + coastal-friends-photos-N.zip
```
